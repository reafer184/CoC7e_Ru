# CoC7e_Ru — русификация Call of Cthulhu 7th Edition для Foundry VTT

Два независимых модуля, которые накладываются **поверх** системы
[CoC7](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT).
Файлы системы не изменяются, патчей её кода нет.

| Модуль | Что делает |
| --- | --- |
| [`coc7-ru-fixes`](coc7-ru-fixes/) | Русские строки интерфейса: лист сыщика и мастер создания персонажа |
| [`coc7-ru-content`](coc7-ru-content/) | Русские CoCID-компендиумы: навыки, профессии, архетипы, наборы правил, оружие, фобии/мании, таблицы, предыстория |

Модули работают и по отдельности, но вместе дают полностью русский процесс
создания сыщика: `coc7-ru-content` даёт названия документов, `coc7-ru-fixes` —
подписи, кнопки и подсказки вокруг них.

## Установка по manifest URL

Foundry → **Настройка** → **Модули** → **Установить модуль** → в поле
«Manifest URL» вставить ссылку и нажать «Установить»:

```
https://raw.githubusercontent.com/reafer184/CoC7e_Ru/ai/ru-investigator-overhaul/coc7-ru-fixes/module.json
```

```
https://raw.githubusercontent.com/reafer184/CoC7e_Ru/ai/ru-investigator-overhaul/coc7-ru-content/module.json
```

Ставить можно в любом порядке, оба — поверх уже установленной системы CoC7.
Затем в мире: **Настройки** → **Управление модулями** → включить оба, и
**Настройки** → **Основные** → язык **Русский**.

Язык мира обязателен: система выбирает документы по
`flags.CoC7.cocidFlag.lang`, и без русского языка продолжит брать английские.

### Ручная установка

Распаковать архив из [`dist/`](dist/) в `Data/modules/<id модуля>/`:

- [`dist/coc7-ru-fixes.zip`](dist/coc7-ru-fixes.zip)
- [`dist/coc7-ru-content.zip`](dist/coc7-ru-content.zip)

## Совместимость

- Foundry VTT 12–13
- Система CoC7 версии 0.10.4 и новее

## Состояние перевода

- Лист сыщика и мастер создания персонажа — переведены (интерфейс и контент).
- Компендиумы системы (навыки, оружие, фобии/мании, таблицы безумия, наборы
  правил, профессия и архетип из примеров) — переведены.
- Не переведены: интерфейс Chaosium Canvas, окна заклинаний, часть настроек
  системы, тексты ошибок, диалог «Бросок как модификатор», строки импортёров
  листов — эти области лежат вне листа и мастера создания.
- Демонстрационные актёры системы (`en-examples`) оставлены на английском.

Подробности по каждому модулю — в его `README.md` и `translation-notes.md`.
