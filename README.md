# CoC7e_Ru — русификация Call of Cthulhu 7th Edition для Foundry VTT

Два независимых модуля, которые накладываются **поверх** системы
[CoC7](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT).
Файлы системы не изменяются, патчей её кода нет.

| Модуль | Что делает |
| --- | --- |
| [`coc7-ru-fixes`](coc7-ru-fixes/) | Русские строки интерфейса: лист сыщика и мастер создания персонажа |
| [`coc7-ru-content`](coc7-ru-content/) | Русские CoCID-компендиумы: навыки, профессии, архетипы, наборы правил, оружие, фобии/мании, таблицы, предыстория |

Модули работают и по отдельности, но вместе дают полностью русский процесс
создания сыщика: `coc7-ru-content` даёт названия документов, `coc7-ru-fixes` —
подписи, кнопки и подсказки вокруг них.

## Установка по manifest URL

Foundry → **Настройка** → **Модули** → **Установить модуль** → в поле
«Manifest URL» вставить ссылку и нажать «Установить»:

```
https://raw.githubusercontent.com/reafer184/CoC7e_Ru/ai/ru-investigator-overhaul/coc7-ru-fixes/module.json
```

```
https://raw.githubusercontent.com/reafer184/CoC7e_Ru/ai/ru-investigator-overhaul/coc7-ru-content/module.json
```

Ставить можно в любом порядке, оба — поверх уже установленной системы CoC7.
Затем в мире: **Настройки** → **Управление модулями** → включить оба, и
**Настройки** → **Основные** → язык **Русский**.

Язык мира обязателен: система выбирает документы по
`flags.CoC7.cocidFlag.lang`, и без русского языка продолжит брать английские.

### Ручная установка

Распаковать архив из [`dist/`](dist/) в `Data/modules/<id модуля>/`:

- [`dist/coc7-ru-fixes.zip`](dist/coc7-ru-fixes.zip)
- [`dist/coc7-ru-content.zip`](dist/coc7-ru-content.zip)

## Совместимость

- Foundry VTT 12–13
- Система CoC7 версии 0.10.4 и новее

## Состояние перевода

**Терминология — по официальному русскому изданию.** Названия навыков, характеристик,
состояний и разделов листа сверены с печатным изданием «Зов Ктулху», 7-я редакция
(Мир Хобби / Hobby World) по официальным листам сыщика и наборам готовых персонажей:
Spot Hidden — «Внимание», Fast Talk — «Красноречие», Credit Rating — «Средства»,
Track — «Чтение следов», Natural World — «Естествознание», Locksmith — «Взлом»,
Mechanical/Electrical Repair — «Механика»/«Электрика», Demolitions — «Взрывчатка»,
Library Use — «Работа в библиотеке»; сокращения СИЛ, ВЫН, ТЕЛ, ЛВК, НАР, ИНТ, МОЩ, ОБР,
РАС, ПЗ, ПМ, БкУ, Компл., СКО; специализация в скобках — со строчной буквы
(«Стрельба (пистолет)»). Ссылки на источники — в `translation-notes.md` обоих модулей
и в [`glossary.md`](glossary.md).

**Интерфейс — 100 %.** В языковом файле системы 1620 строковых ключей; штатный `ru.json`
плюс 731 ключ `coc7-ru-fixes` и 109 имён CoCID из `coc7-ru-content` покрывают все,
кроме восьми служебных, которые совпадают с английскими по смыслу (`ID`, `Foundry ID`,
`Foundry UUID`, форматы чисел и подстановок) — включая интерфейс Chaosium Canvas,
окна заклинаний, настройки системы и Pulp Cthulhu, тексты ошибок, импортёры листов,
карточки боя и погони, поведения регионов и диалог «Бросок как модификатор».

**Контент — весь, что есть в системе:** 103 навыка, 53 предмета оружия, 20 фобий и маний,
таблицы приступов безумия, набор правил, профессия, архетип, талант,
заклинание плюс шесть новых таблиц предыстории.

Авторская часть перевода (издания этих терминов не содержат): навыки эпох
Gaslight, Invictus и Down Darker Trails, редкие специализации ближнего боя и стрельбы,
шесть языков, «Вождение экипажа / конной упряжки / повозки или дилижанса» и таблицы предыстории.

Сознательно остались на английском:

- демонстрационные актёры системы (`en-examples`: НПС, существа, контейнеры);
- технические подписи `ID`, `Foundry ID`, `Foundry UUID`;
- редкие строки, вписанные в `.hbs`-шаблоны мимо `game.i18n` — их можно
  исправить только правкой системы;
- контент из платных книг — в системе его нет.

Подробности по каждому модулю — в его `README.md` и `translation-notes.md`.
