# CoC7 Russian Localization Fixes

Модуль-надстройка для исправления русской локализации листа Investigator и мастера создания персонажа в системе Call of Cthulhu 7e для Foundry VTT.

## Установка для разработки

1. Скопируйте папку `coc7-ru-fixes` в каталог `Data/modules/` Foundry VTT либо создайте junction на неё.
2. Включите модуль в **Manage Modules** нужного мира.
3. Выберите русский язык в **Configure Settings → Core → Language**.
4. Перезапустите Foundry или выполните `Ctrl+F5`.

## Область текущего исправления

- Недостающие ключи интерфейса листа Investigator: броня, пакеты опыта, прогресс чтения книг, Active Effects.
- Терминология статусов, навыков, очков развития, предметов и потери рассудка.
- Wizard и лист `investigator-v3`, если они используют соответствующие `CoC7.*`-ключи.

## Ограничение

Названия и описания навыков, профессий, архетипов, сетапов и предысторий могут поступать из Compendium-документов CoCID, а не из `lang/ru.json`. Для их полной редакторской русификации нужен отдельный content-пак.
