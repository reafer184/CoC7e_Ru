# CoC7 Russian Localization Fixes

Модуль-надстройка для Foundry VTT, который приводит русский интерфейс мастера
создания сыщика и листа Investigator системы
[Call of Cthulhu 7th Edition](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT)
к единой редакционной норме. Файлы системы не изменяются: исправленные строки
накладываются поверх штатного словаря.

## Как это работает

Два слоя, чтобы результат не зависел от порядка загрузки языковых файлов:

1. `lang/ru.json` регистрируется в `module.json` как языковой файл модуля.
   Foundry сливает его со словарём системы при инициализации локали.
2. `scripts/main.js` на хуке `ready` повторно применяет тот же самый файл через
   `foundry.utils.mergeObject(..., { overwrite: true })`. Словарь в скрипте не
   дублируется — он читает `lang/ru.json`, поэтому оба слоя всегда совпадают.

Скрипт срабатывает только при активном русском языке интерфейса.

и именами из `coc7-ru-content` закрыты все 1649 ключей `static/lang/en.json`:
английских строк в локализации больше не осталось.

## Установка для разработки

```powershell
cmd /c mklink /J `
    "%LOCALAPPDATA%\FoundryVTT\Data\modules\coc7-ru-fixes" `
    "%USERPROFILE%\FoundryDev\CoC7e_Ru\coc7-ru-fixes"
```

1. Полностью перезапустите Foundry VTT.
2. В мире CoC7 включите модуль в **Manage Modules**.
3. Выберите русский язык в **Configure Settings → Core → Language**.
4. Нажмите `Ctrl+F5`.

В консоли браузера должно появиться сообщение
`coc7-ru-fixes | Исправления русской локализации применены: 724 строк.`

## Важно: названия специализаций

Система определяет свойства навыка сравнением строк: в
`models/item/skill-system.js` свойство `fighting`, `firearm` или `ranged`
выставляется, если `system.specialization` равно
`game.i18n.localize('CoC7.FightingSpecializationName')` и так далее. Поэтому
эти ключи приведены к названиям из паков `coc7-ru-content`:

| Ключ | Штатный `ru.json` | Здесь |
| --- | --- | --- |
| `CoC7.FightingSpecializationName` | Борьба | **Ближний бой** |
| `CoC7.FirearmSpecializationName` | Огнестрельное оружие | **Стрельба** |
| `CoC7.RangedSpecializationName` | — | Дальний бой |
| `CoC7.LanguageSpecializationName` | — | Язык |
| `CoC7.DriveSpecializationName` | Вождение | Вождение |
| `CoC7.PilotSpecializationName` | Пилотирование | Пилотирование |

Без этого вручную созданный навык «Стрельба (Пистолет)» не получил бы
свойство `firearm`, а импортёр листов не нашёл бы соответствий в компендиумах.
Виды оружия (`CoC7.SkillNameHandgun` и далее) тоже сверены с именами навыков
в паках: Пистолет, Винтовка/Дробовик, Пистолет-пулемёт, Пулемёт.

## Чего этот модуль не исправляет

- **Названия и описания навыков, профессий, архетипов, наборов правил,
  предысторий, оружия, книг, заклинаний и талантов.** Мастер загружает
  CoCID-документы (`i.skill.*`, `i.occupation.*`, `i.archetype.*`,
  `i.setup.*`, `rt..backstory-*`) и выводит `item.name`, поэтому UI-словарь их
  не переименует. Для них нужен отдельный content-пак `coc7-ru-content`.
- **Буквальные английские строки в `.hbs`-шаблонах**, которые вообще не проходят
  через `game.i18n` (например `title="Throw"`). Такие места правятся upstream-PR
  или переопределением шаблона.
- **Строки самого Foundry VTT** (общие кнопки и меню ядра) — их переводит
  языковой пакет самого Foundry, а не этот модуль.

## Обновление словаря

Строки собираются скриптом сверки из `static/lang/en.json`,
`static/lang/ru.json` upstream-проекта и экспорта
`source/coc7-ru-full-source.json`. При обновлении CoC7 сверку стоит повторить:
проверяются наличие ключа в `en.json`, совпадение плейсхолдеров вида `{count}`
и полнота покрытия используемых ключей.
