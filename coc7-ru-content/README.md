# coc7-ru-content

Русские CoCID-компендиумы для системы **Call of Cthulhu 7th Edition** (Foundry VTT).

Модуль **не изменяет** файлы системы `CoC7` и не патчит её код. Он добавляет свои
компендиумы, документы в которых помечены `flags.CoC7.cocidFlag.lang: "ru"`.
Система сама предпочитает их английским: в `coc7/apps/coc-id.js` метод
`#filterByLanguage` отбрасывает кандидатов с `lang: "en"`, если для того же CoCID
есть документ на языке интерфейса, а `#compareCoCIDPriority` сортирует остаток по
`priority`. Поэтому мастер создания сыщика и лист персонажа получают русские
навыки, профессии, архетипы и таблицы без каких-либо перехватов.

Второй модуль репозитория, `coc7-ru-fixes`, отвечает за строки интерфейса.
Этот модуль — за сами документы.

## Основа терминологии

Названия навыков, оружия и разделов листа взяты из **официального русского издания
«Зов Ктулху», 7-я редакция (Мир Хобби / Hobby World)** — по официальным листам сыщика и
наборам готовых персонажей (ссылки в `translation-notes.md`). Специализация пишется
в скобках со строчной буквы: «Стрельба (пистолет)», «Ближний бой (драка)», «Наука (биология)».
Там, где издание навыка не содержит (эпохи Gaslight, Invictus, Down Darker Trails и редкие
специализации), название составлено по книжному образцу — это авторская часть перевода.

## Таблицы предыстории (`rt..backstory-*`)

В базовой системе таких таблиц нет — есть только ключи имён
`CoC7.CoCIDFlag.keys.rt..backstory-*`, которые мастер создания сыщика
использует на шаге «Предыстория»: если название секции биографии совпадает с
таким ключом и найдена таблица с соответствующим CoCID, рядом с полем появляется
кнопка броска.

Поэтому модуль добавляет шесть собственных русских таблиц с оригинальным
содержимым (по 10 записей, `1d10`):

- `rt..backstory-ideology-and-beliefs` — Мировоззрение и убеждения
- `rt..backstory-significant-people` — Значимые люди
- `rt..backstory-meaningful-locations` — Важные места
- `rt..backstory-treasured-possessions` — Дорогие вещи
- `rt..backstory-traits` — Черты характера
- `rt..backstory-injuries-and-scars` — Травмы и шрамы

Русский `i.setup.s-setup` объявляет секции биографии именно этими ключами, так что
после выбора набора правил кнопки бросков в мастере работают сразу.

## Установка

1. Скопировать папку `coc7-ru-content` в `Data/modules/` сервера Foundry.
2. Включить модуль в мире с системой CoC7.
3. Язык мира должен быть русским (`ru`) — иначе система продолжит выбирать
   английские документы.

## Проверка в Foundry

В консоли браузера (F12):

```js
await game.modules.get('coc7-ru-content').api.report()   // все CoCID модуля
await game.modules.get('coc7-ru-content').api.resolve()  // что реально выберет система
await game.modules.get('coc7-ru-content').api.resolve(['i.skill.credit-rating'])
```

Ожидаемо в колонке `lang` — `ru`, в колонке `pack` — компендиум
`coc7-ru-content.*`.

Дальше в интерфейсе:

- «Создать персонажа» → шаг «Набор правил»: «Пример набора правил (1920-е)».
- Шаг «Профессия»: «Уличный торговец»; шаг «Архетип»: «Миротворец».
- Шаг «Навыки»: русские названия, «Средства» и «Мифы Ктулху» на месте.
- Шаг «Предыстория»: у пяти секций из шести есть кнопка броска по таблице.
- Лист сыщика: навыки подписаны по-русски, специализации сгруппированы
  («Стрельба», «Ближний бой», «Наука», «Язык»).

## Сборка компендиумов

Источник правды — YAML в `compendiums/`. Бинарные паки (LevelDB) собираются из них:

```bash
cd coc7-ru-content/tools
npm install
cd ..
node tools/build-packs.mjs
```

Логика сборщика повторяет системную (`scripts/src/generate-compendiums.js` и
`template-helpers.js`): детерминированные `_id` из `md5(имя + lang + eras)`,
ключи `!items!<id>`, `!folders!<id>`, `!tables!<id>`, вложенные результаты
таблиц `!tables.results!<id>.<id>`, а для навыков из имени вида
«Специализация (Уточнение)» выводятся `system.specialization` и
`system.skillName`.

Дополнение сверх системного сборщика: в результате таблицы можно указать
`documentCoCID: i.status.acrophobia` — сборщик сам подставит `documentCollection`
и `documentId`, поэтому ссылки между таблицами и фобиями не приходится
поддерживать вручную.

## Что осталось на английском

- Примеры актёров (`en-examples.yaml`: NPC, существа, контейнеры) — не переводились,
  это демонстрационные листы, а не контент мастера создания.
- Профессии и архетипы из платных книг: в системе их нет, они приходят
  отдельными модулями. Для их русификации нужно добавить документы с теми же
  CoCID в `compendiums/ru-occupations.yaml` и пересобрать паки.

## Лицензия и источник

Структура документов, характеристики и CoCID взяты из системы
[CoC7-FoundryVTT](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT)
(Miskatonic Investigative Society). Переведены имена и описания; игровые значения
не изменялись, кроме двух исправлений явных опечаток CoCID (см.
`translation-notes.md`). Текст таблиц предыстории написан для этого модуля с нуля.
